Acerca de este proyecto

Descripción

Esta es una aplicación Flask moderna construida siguiendo las mejores prácticas y técnicas actuales. Utiliza SQLAlchemy como ORM principal para la gestión de la base de datos SQLite3.

Tecnologías Utilizadas

  • Flask 3.0 - Framework web Python
  • SQLAlchemy 2.0 - ORM para base de datos
  • Flask-Migrate - Migraciones de base de datos
  • Flask-WTF - Formularios con validación
  • Flask-Login - Gestión de sesiones de usuario
  • Flask-Limiter - Rate limiting para seguridad
  • SQLite3 - Base de datos ligera

Estructura del Proyecto

project/

├── migrations/          # Migraciones de base de datos
├── tests/               # Tests unitarios
├── .env.example         # Ejemplo de variables de entorno
├── requirements.txt     # Dependencias del proyecto
